# Firefox corrective action and targeted regression

The initial browser run recorded all 16 Firefox cross-browser cases as **BLOCKED** because the pinned Playwright Firefox launcher exited with `Could not find profile folder`. These blocked cases were not counted as browser passes. The initial evidence and manifest are preserved byte-for-byte under `initial_run/`.

The pinned Playwright Firefox browser was reinstalled, but its smoke test still failed with the same profile error (`logs/firefox_smoke_test.log`). The tester had installed `/Applications/Firefox.app`; verification found Mozilla Firefox 157.0. Explicitly directing Playwright to that installed executable also failed with the profile error (`logs/system_firefox_smoke_test.log`). A direct GeckoDriver launch failed as well (`logs/geckodriver_verbose.log`). The Playwright launcher issue was therefore **not fixed**.

The successful recovery used the installed Mozilla Firefox, not a substitute browser. macOS LaunchServices started a separate Firefox process with a fresh temporary profile; GeckoDriver attached to that isolated process using `--connect-existing`, and Selenium/WebDriver controlled the page. The normal Firefox process and profile were left untouched. The successful smoke test is recorded in `logs/firefox_launchservices_probe.log`. The targeted matrix used WebDriver BiDi viewport control after navigation so the mobile cases ran at the measured 390 × 844 CSS-pixel viewport; `logs/firefox_viewport_probe2.log` records that check.

Early matrix attempts exposed harness defects and were retained as preflight evidence (`logs/firefox_matrix_preflight_results.csv` and `logs/firefox_matrix_viewport_preflight_results.csv`), not treated as app failures. The first valid 16-case matrix passed 15/16; the desktop `/watchlist` case timed out once. Five fresh-session retries of that exact case passed 5/5 (`firefox_watchlist_retest_results.csv`). A subsequent complete targeted matrix passed 16/16 (`firefox_cross_browser_results.csv`, with dated raw records; screenshots were later excluded from repository storage). A separate final clean matrix is recorded under `../final_run/`.

Firefox assertions cover HTTP success, visible primary and route-specific content, navigation, viewport and overflow, page errors, console errors, and critical same-origin request failures. Chromium and WebKit remained on the pinned Playwright harness. The different Firefox automation method must be disclosed wherever the combined cross-browser result is reported.
