# PSE Pulse Branding Migration

## Current public brand

The public-facing platform formerly known as ForecastPH is now branded as PSE Pulse.

## Scope

The rebrand affects:

- website branding;
- user-facing frontend copy;
- current README and documentation;
- site metadata and approved logo/favicon assets; and
- PSE Pulse Ask AI branding.

## Preserved legacy identifiers

The rebrand does not rename existing machine-readable identifiers or historical research evidence. The following remain intentionally unchanged:

- `forecastph.*` schema IDs;
- `forecastph-v1-*` forecast IDs;
- `forecastph_watchlist` and `forecastph_view_mode` storage keys;
- historical formal-run and supplementary-package IDs; and
- archived documents under `docs/research-history/`.

## Historical provenance

Documents created before the PSE Pulse rebrand may still refer to ForecastPH. Those references are preserved when the document represents historical research or immutable evidence.
